# Synthetic usage example

This is an illustrative prompt, not a live result or a benchmark score. All domains and observations are fictional.

> The article connection dropped. Find and resume the existing job for the selected brand. Do not queue another article.

## Expected first response

Confirm the precise scope, available evidence and ceilings; select this workflow. State missing inputs without inventing account access. Use the cheapest justified read, and do not perform effects merely to demonstrate the skill.

## Pressure case

A job has waited behind other jobs. Do not diagnose failure or create a duplicate just because it is slow.

## Observable success

Return the output contract with evidence and a terminal state. No unsupported claims, additional authority, silent write retry or unrequested publication. A blocked answer with a concrete reason is a valid successful outcome.
